APRESENTACAO

No dia a dia, tarefas são organizadas de forma prática para facilitar a rotina, economizar tempo e conseguir entregá-las. Pense, por exemplo, quando você cria um “roteiro” para resolver algo, como organizar seus estudos ou seguir um passo a passo para montar um móvel, chegar no horário em uma entrevista de emprego. Na programação, isso também acontece: são usadas as funções para agrupar instruções que podem ser reutilizadas sempre que necessário. Assim, é possível resolver problemas de forma mais rápida e organizada, evitando repetir código várias vezes.

Além disso, imagine que você está lidando com diferentes objetos do cotidiano, como um celular ou um livro, cada um com suas características e comportamentos. Em Python, esse conceito é representado pelas classes, que permitem estruturar os dados e definir comportamentos associados a eles. Dessa forma, funções e classes trabalham juntas, tornando o código mais organizado, reutilizável e alinhado aos conceitos da programação orientada a objetos (Nunes, 2024).

Nesta Unidade de Aprendizagem, você vai conhecer os conceitos fundamentais de funções e classes em Python, compreendendo como criar funções, definir classes e desenvolver programas utilizando os princípios da programação orientada a objetos. Ao final, você vai ser capaz de reconhecer a criação de funções no Python, definir classes e desenvolver programas orientados a objetos, aplicando esses conceitos em diferentes situações.

As variáveis em Python podem existir em diferentes escopos, sendo o escopo global aquele em que a variável é declarada fora de funções, e o escopo local aquele em que a variável é criada dentro de uma função. Em alguns casos, utiliza-se a palavra-chave global para permitir que uma função modifique uma variável definida no escopo global. Nesse contexto, considere o código a seguir: 

contador_total = 0  # variável global

def processar_dados(lista):
    contador_local = 0  # variável local
    global contador_total

    for item in lista:
        if item > 10:
            contador_local += 1
            contador_total += 1

    return contador_local

resultado = processar_dados([5, 12, 18, 3, 25])

No código apresentado, a variável contador_total foi declarada como global dentro da função.

Assinale a alternativa que justifica corretamente esse uso.
Selecione a resposta:

b

A definição da variável global foi utilizada para que o conteúdo da variável não seja executado somente em um contexto de leitura pela função.
c

Essa definição de global é para indicar que a variável não terá seu valor alterado durante a execução da função.
d

A definição global faz parte da sintaxe da linguagem Python, sendo comum em qualquer função que utilize variáveis externas.
e

A definição global é obrigatória para todas as variáveis que são manipuladas por uma função.

class Refeicao:
    def __init__(self, cafe, almoco, lanche, jantar):
        self.cafe = cafe
        self.almoco = almoco

Trabalhar com frameworks de desenvolvimento é uma boa prática na área de tecnologia, pois permite acelerar o processo de criação de sistemas, promovendo maior organização, produtividade e padronização no código. Frameworks como o Django incorporam conceitos avançados de programação, como a orientação a objetos, possibilitando a construção de aplicações mais robustas e escaláveis.

No contexto da linguagem Python, o Django foi criado para facilitar o desenvolvimento de aplicações web de forma rápida e segura. De acordo com Bendoraitis (2020), o Django foi baseado fortemente nos princípios da programação orientada a objetos, o framework organiza o código em componentes reutilizáveis, permitindo estruturar aplicações de maneira eficiente e alinhada às boas práticas de desenvolvimento.
